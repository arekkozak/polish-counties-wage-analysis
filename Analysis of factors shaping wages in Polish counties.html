1. Wprowadzenie danych

Celem badania jest zbudowanie modelu ekonometrycznego tłumaczącego kształtowanie się przeciętnego miesięcznego wynagrodzenia brutto w polskich powiatach. Dane zostały pobrane z bazy Głównego Urzędu Statystycznego (GUS). Do analizy wytypowano następujące zmienne: Zmienna objaśniana (Y): Przeciętne miesięczne wynagrodzenie brutto (w PLN).
Zmienne objaśniające (X):

  • X1: Dochody gmin per capita (PLN)
  • X2: Stopa bezrobocia (%)
  • X3: Ceny mieszkań (PLN/m2)
  • X4: Liczba ludności na km2 (gęstość)
  • X5: Wydatki na edukację per capita (PLN)
  • X6: Liczba podmiotów gospodarczych (REGON) per capita

Jak widać wśród danych występują liczne wartości odstające. W celu usunięcia outlinerów zaburzających estymację zastosowano metodę opartą na rozstępie międzykwartylowym (IQR).

usun_outliery <- function(dane) {
  dane_czyste <- dane
  kolumny <- c("wynagrodzenie", "dochody", "bezrobocie", "ceny_mieszkan", 
               "ludnosc", "edukacja_pc", "regon_pc")
  
  for (kol in kolumny) {
    Q1 <- quantile(dane_czyste[[kol]], 0.25, na.rm = TRUE)
    Q3 <- quantile(dane_czyste[[kol]], 0.75, na.rm = TRUE)
    IQR <- Q3 - Q1
    
    dolna_granica <- Q1 - 3 * IQR
    gorna_granica <- Q3 + 3 * IQR
    
    dane_czyste <- dane_czyste %>%
      filter(get(kol) >= dolna_granica & get(kol) <= gorna_granica)
  }
  return(dane_czyste)
}

df_czyste <- usun_outliery(df_ln)
print(paste("Liczba obserwacji przed czyszczeniem:", nrow(df_ln)))
## [1] "Liczba obserwacji przed czyszczeniem: 380"
print(paste("Liczba obserwacji po usunięciu outlierów:", nrow(df_czyste)))
## [1] "Liczba obserwacji po usunięciu outlierów: 363"

7. Predykcja na zbiór testowy i analiza błędów ex post

prognozy_ln <- predict(model_ostateczny, newdata = df_test)

# Porównanie prognozy z rzeczywistością (przywrócenie wartości zlogarytmowanych na PLN)
rzeczywiste_place <- exp(df_test$wynagrodzenie)
przewidziane_place <- exp(prognozy_ln)
bledy <- rzeczywiste_place - przewidziane_place

mae <- mean(abs(bledy))
rmse <- sqrt(mean(bledy^2))
mape <- mean(abs(bledy / rzeczywiste_place)) * 100

cat("Statystyki błędów na zbiorze testowym:\n",
    "MAE: ", round(mae, 2), " PLN\n",
    "RMSE: ", round(rmse, 2), " PLN\n",
    "MAPE: ", round(mape, 2), " %")
## Statystyki błędów na zbiorze testowym:
##  MAE:  350.17  PLN
##  RMSE:  429.37  PLN
##  MAPE:  4.68  %

Uzyskane wyniki predykcji świadczą o wysokiej jakości zbudowanego modelu. Relatywnie niewielka różnica między RMSE a MAE wskazuje na stabilność modelu. Średnio prognozowane wyniki różnią się o 350,17 zł od płac rzeczywistych. Błąd procentowy MAPE na poziomie 4,68% potwierdza, że model bardzo precyzyjnie wyjaśnia zróżnicowanie wynagrodzeń w polskich powiatach, mimo wcześniejszych problemów z normalnością reszt.

8. Podsumowanie

Ostateczne równanie:

ln(wynagrodzenie) = 7,5455 + 0,1475⋅ln(dochody) + 0,0016⋅bezrobocie + 0,0506⋅ln(ceny_mieszkan) + 0,0125⋅ln(ludnosc) - 0,0428⋅ln(edukacja_pc)

Interpretacja:

  • Dochody samorządów: Wzrost dochodów własnych powiatu o 1% wiąże się ze średnim wzrostem wynagrodzeń o ok. 0,15%.
  • Bezrobocie: Wzrost bezrobocia o 1% skutkuje wzrostem wynagrodzeń o ok. 0,002%.
  • Ceny mieszkań: Wzrost cen nieruchomości o 1% przekłada się na wzrost płac o ok. 0,05%
  • Ludność: Wzrost populacji o 1% skutkuje wzrostem wynagrodzeń o ok. 0,01%.
  • Edukacja: Wzrost wydatków na edukację o 1% powoduje spadek wynagrodzeń o ok. 0,04%.

Przeprowadzona analiza wykazała, że kluczowymi determinantami wynagrodzeń w polskich powiatach są dochody jednostek samorządu terytorialnego oraz sytuacja na rynku nieruchomości. Skorygowany współczynnik determinacji wskazuje, że model wyjaśnia ponad 43% zmienności płac, co w przypadku danych przekrojowych na poziomie lokalnym jest wynikiem satysfakcjonującym. Wysoką zdolność predykcyjną modelu potwierdza analiza ex post – średni błąd prognozy na poziomie 4,68% dowodzi, że model charakteryzuje się bardzo dużą dokładnością i może być z powodzeniem wykorzystywany do celów analitycznych.
